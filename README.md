# Student Quiz Challenge

## Project Overview

Student Quiz Challenge is a browser-based quiz application developed as part of the CIS046-3 Software for Enterprise assignment.

The application allows users to enter a username and answer mathematical puzzle questions provided by the Banana Game API. Users receive feedback after submitting answers and earn points for correct answers.

## Technologies Used

- **HTML5** – Provides the structure of the application.
- **CSS3** – Controls the layout, colours and visual design.
- **JavaScript** – Handles user interaction, question loading, answer checking and scoring.
- **Banana Game API** – Supplies mathematical puzzle images and their solutions.
- **Git and GitHub** – Used for version control and source-code management.

## Features

- Username entry and welcome message.
- Random mathematical puzzle questions.
- External API integration.
- Answer validation.
- Immediate feedback for correct and incorrect answers.
- Score tracking.
- Ten questions per game.
- Final results screen.
- Play Again functionality.

## How to Run the Application

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Enter a username and select **Start Quiz**.
5. Answer the questions and view your final score.

An internet connection is required to retrieve questions from the Banana Game API.
